# FujiBlast's H89 art: the H19 terminal's characters (tools/mkgfx_h89.py
# turns this into gen/h89). The game's own art, drawn for the H19; no
# Bomberman (see the README).
#
# A cell item is a [NAME] line, then a line a row:   |chars| mask
#   chars  the bytes sent in graphics mode: 20h-5Dh print as themselves
#          (upper case, digits, punctuation); these are graphics:
#            `  vertical line        a  horizontal line     b  cross
#            c  corner, upper right  d  lower right          e  lower left
#            f  upper left           i  checkerboard         l m n o  one
#            quadrant: LR LL UL UR   p  upper half           q  right half
#            r  filled triangle, upper left    _  ... upper right
#            s t u v  tees: stem down, left, up, right       w  diagonal cross
#            x  /    y  \    z  bar along the top    {  bar along the bottom
#            |  bar along the left   }  ... the right   ^  bullet
#          @  (sprites) the seat's digit
#   mask   one letter a cell (missing: all normal): . normal, R reversed
#          (reversed p: the lower half; r: the lower-right triangle...),
#          T see-through (sprites)
#
# A bitmap item is a [NAME bitmap] line, then rows of X (on) and . (off),
# two a cell row: each cell becomes a half block (p, reversed p, reversed
# space).
