# art.txt -- FujiBlast's pictures for the RCA Studio II, 1 bit a pixel.
# tools/s2/mkart_s2.py turns them into build/studio2/art.inc and previews.
#
# On a TV a Studio II pixel is about 3.3 lines wide: a tile here is 4
# pixels by 10 lines, near square. X lit, . dark. Every object class has a
# texture no other class uses (the user's brief: all players and objects
# distinct on a monochrome screen).
#
# @tile NAME        a 4 x 10 tile (stamped, SET mode: the floor erases)
# @icon NAME W      a W-wide picture, any height (the HUD, the trophy)
# @gear SEAT VIEW   rows 0-3 of a bomber, ORed over the head (VIEW: front,
#                   back, side -- side faces right; left is its mirror)
# @head VIEW        rows 2-6: the head and the neck
# @body SEAT VIEW   rows 7-10
# @legs VIEW N      rows 11-13, walk frame N (0 standing, 1, 2)
# @frame SEAT NAME  a whole 14-row figure (knocked out, cheering); SEAT *
#                   = every seat, with that seat's gear ORed over rows 0-3
#                   where the frame says `gear` (a line of its own).
